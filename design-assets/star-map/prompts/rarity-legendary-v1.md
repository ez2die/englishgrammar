# Legendary 基础星徽 V1

参考图:`../source/style-master-v1.png` 与 `../rarities/epic-base-v1.png`。

保持 Epic 所属的圆角五角星家族轮廓、正视方向和居中规则。Legendary 使用琥珀金、蜂蜜黄和淡金高光,采用四层皇冠式边纹/光环,并在外缘紧贴四个小型钻石光芒。中心保持简洁,供后续叠加成就图腾;庆祝感强于 Epic,但不得金属化或过度华丽。

背景必须是均匀 `#00ff00` 纯色,无渐变、纹理、反射、地面、光照变化或投影。主体不得使用绿色。禁止文字、字母、数字、徽章底板、扇贝边框、长流星拖尾、倒角、宝石切面、3D 浮雕和水印。
