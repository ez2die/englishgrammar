# 勤学座成就星标批次 V1（正式采用）

参考：Common、Rare、Epic、Legendary 四档稀有度底座，以及 `../review/stars-start-v1-contact-sheet.png` 的成就星标家族风格。

在方形画布上生成严格 2×2 网格、尺寸一致且互不重叠的四枚星形勋章：

1. 左上 `diligent.10`：Common 象牙星徽，内部为蓝色封面、象牙书页的单本小书。
2. 右上 `diligent.50`：Rare 天蓝星徽，内部为恰好三本蓝、象牙、琥珀色圆角书堆。
3. 左下 `diligent.100`：Epic 紫罗兰星徽，内部为带三枚金色对勾的卷轴，不含文字或数字。
4. 右下 `diligent.500`：Legendary 琥珀金星徽，内部为一艘由展开书本构成的小帆船，配一面靛蓝三角帆与一道蓝色波浪。

使用轻量扁平 2.5D 矢量插画、宽圆形状、中等靛蓝描边、每色块最多一层微弱渐变。背景为完全均匀的纯 `#00FF00` 绿色抠图色。不得生成面板、分隔线、文字、数字、外发光、投影、粒子、星座线或水印。
