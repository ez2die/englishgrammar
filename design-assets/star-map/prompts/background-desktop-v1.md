# 桌面/平板星图背景 v1

- 模式：内置 imagegen
- 用途：`stylized-concept`
- 交付：`backgrounds/desktop-v1.webp`，3840×2160，不透明 WebP
- 参考：`source/background-mobile-v1-source.png`

## Prompt

Create a true 16:9 landscape companion to the approved portrait star-map background. Recompose rather than stretch: preserve the same deep-indigo to muted-violet sky, restrained cyan/violet nebula haze at only the far outer edges, sparse tiny dust, soft rounded hills along the bottom 14%, and the same tiny observatory with one warm amber window slightly right of center. Keep the central 75% and top UI band dark, calm and visually quiet for dynamic constellation nodes, lines, labels and progress UI. Match the premium child-friendly storybook game-UI rendering exactly. No text, logos, large stars, achievement icons, fixed constellation points or lines, moon, planets, comets, characters, mascots, foreground UI, frame or border.

## 后处理与验收

生成源按中心构图等比裁切并缩放到 3840×2160，导出高质量 WebP。与移动版并排检查配色、地标、边缘星云密度和中央安全区一致性。
