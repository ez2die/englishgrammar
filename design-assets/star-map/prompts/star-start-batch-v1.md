# 启程座成就星标批次 V1（正式采用）

参考：Common 稀有度底座 `../rarities/common-base-v1.png`、Rare 稀有度底座 `../rarities/rare-base-v1.png`、轻量插画风格 `../constellations/diligent-v1.png`。

在横向画布上生成严格 1×3 网格、尺寸一致且互不重叠的三枚星形勋章：

1. `start.first_q`：Common 象牙星徽，内部为两片叶子的圆润嫩芽，不含花盆或泥土。
2. `start.first_checkin`：Common 象牙星徽，内部为空白天蓝日历、两个装订环与一枚金色对勾，不含数字或字母。
3. `start.first_perfect`：Rare 天蓝双层星徽，内部为较小的暖金五角星。

使用宽形、圆润、轻量 2.5D 矢量插画，中等靛蓝描边，每个色块最多一层微弱渐变。背景为完全均匀的纯 `#FF00FF` 洋红抠图色。不得生成面板、分隔线、标签、文字、数字、外发光、投影、粒子、星座线或水印。
