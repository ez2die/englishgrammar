# 语法星图资产验收规范

本规范适用于 `production-plan.json` 中的全部 53 项交付物。

## 通用门禁

- 风格必须引用 `source/style-master-v1.png`,保持圆润扁平、细描边、哑光色块和克制辉光。
- 不得包含文字、水印、品牌标志、固定星座连线或未经定义的装饰主体。
- 每项必须在 `manifest.json` 登记生成源、提示词、参考图、版本、尺寸、SHA-256 和状态。
- 候选图不能被应用引用;只有 `production` 状态可进入代码。
- 修改不得覆盖旧文件,必须递增 `-v2`、`-v3`。

## 透明资产

- 交付格式为 RGBA PNG,四角 Alpha 必须为 0。
- 不允许纯色底残留、明显绿边/品红边、锯齿、脏像素或被裁切的辉光。
- 1024×1024 画布内主体包围盒的最长边建议占画布 62%–76%;非方形图腾的短边可按造型自然收窄,四周仍需保留安全区。
- 抠图底色必须避开主体及其辉光的邻近色:蓝紫/金色资产优先使用品红底,绿色主体使用品红底,无发光且不含绿色的简单图标才使用绿色底。
- 需要透明交付的实体图标/图腾不得在生成源中包含半透明外发光;外发光、星尘与闪烁统一由前端或独立特效层提供,避免任何色键底污染边缘。
- 禁止把非方形生成源强制拉伸为方形。透明资产必须先按 Alpha 包围盒裁切,再等比缩放并居中到 1024×1024 透明画布。
- 源图保存在 `source/`,抠图后的交付图保存在对应分类目录。

## 分类尺寸

| 分类 | 交付尺寸 | Alpha |
|---|---:|---|
| 稀有度底座 | 1024×1024 | 必须 |
| 星座主题图腾 | 1024×1024 | 必须 |
| 星辰图标 | 1024×1024 | 必须 |
| 通用状态/庆祝特效 | 1024×1024 | 必须 |
| 吉祥物 | 1024×1024 | 必须 |
| 移动背景 | 2160×3840 | 不需要 |
| Web/平板背景 | 3840×2160 | 不需要 |
| 空状态/封面 | 2160×3840 | 不需要 |

## 稀有度辨识

- Common:象牙白、小星、单层轮廓、微弱柔光。
- Rare:天蓝/青、略大、双层光环或两段边纹。
- Epic:紫罗兰、更大、三层光环或三段边纹、少量光尘。
- Legendary:琥珀金、最大、四层/皇冠式边纹、可带克制拖尾。
- 除颜色外必须至少再用大小、光环层数或边纹区分,满足色觉可访问性要求。
