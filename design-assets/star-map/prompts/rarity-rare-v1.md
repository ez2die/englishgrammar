# Rare 基础星徽 V1

参考图:`../source/style-master-v1.png` 与 `../rarities/common-base-v1.png`。

严格保持 Common 星徽的圆角五角星轮廓、正视方向、主体比例、中心位置和等距留白。Rare 使用天蓝、青色和冰蓝高光,增加克制的双层边纹/光环,使其在不依赖颜色时也能与 Common 区分。中心保持简洁,供后续叠加成就图腾。

背景必须是均匀 `#00ff00` 纯色,无渐变、纹理、反射、地面、光照变化或投影。主体不得使用绿色。禁止文字、字母、数字、附加星星、漂浮火花、徽章底板、扇贝边框、倒角、宝石切面、3D 浮雕和水印。
