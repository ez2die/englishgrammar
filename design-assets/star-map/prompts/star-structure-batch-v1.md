# 句型座成就星标批次 V1（正式采用）

在横向画布上生成严格 3×2 网格，前五格放星标，第六格完全留空：

1. `structure.sv` Common：卡片内两个蓝色槽位以金线相连。
2. `structure.svo` Common：卡片内三个蓝色槽位横向相连。
3. `structure.sp` Common：蓝色圆槽、金色菱形连接符、紫色圆槽。
4. `structure.svoo` Rare：两个前置槽位后分支到两个较小宾语槽位。
5. `structure.svoc` Rare：四个横向槽位，最后紫色槽位带细金环。

所有卡片不得包含 SV、SVO 等字母或任何文字，字母由前端叠加。沿用批准成就星标的轻量 2.5D 风格。背景为完全均匀的纯 `#00FF00` 绿色抠图色；不得生成第六枚、分隔线、面板、外发光、投影、粒子、星座线或水印。
